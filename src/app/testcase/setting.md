# 1. 检查电源1
- 前提条件:
    1. 打开  app activity ".Settings" , 
    2. app package "com.android.settings"
- 测试步骤:
    1. 找寻「省电与电池」，如果没找到，则向上滚动屏幕直至成功
    2. 点击「省电与电池」
    3. 进入「省电与电池」页面后，获取「剩余电量」
    4. 获取到剩余电量后，断言电量大于0 
    5. 返回上一级页面

# 2. 系统个性化
## 2.1 主题1
- 前提条件:
    1. 打开  app activity ".Settings" , 
    2. app package "com.android.settings"
- 测试步骤: 
    1. 找寻「系统个性化」，如果没找到，则向上滚动屏幕直至成功
    2. 点击「系统个性化」
    3. 进入「系统个性化」页面后，找寻「主题」，如果没找到，则向上滚动屏幕直至成功
    4. 点击「主题」
    5. 进入「个性主题」页面后，断言页面中包含「我的主题」
    6. 返回上一级页面
    7. 返回上一级页面

# 3. 更多链接
## 3.1 打印1
- 前提条件:
    1. 打开  app activity ".Settings" , 
    2. app package "com.android.settings"
- 测试步骤: 
    1. 找寻「更多链接」，如果没找到，则向上滚动屏幕直至成功
    2. 点击「更多链接」
    3. 进入「更多链接」页面后，找寻「打印」，如果没找到，则向上滚动屏幕直至成功
    4. 点击「打印」
    5. 进入「打印」页面后，断言页面中包含「系统打印服务」
    6. 返回上一级页面
    7. 返回上一级页面
