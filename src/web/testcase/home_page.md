# 2. 行政区域
## 2.1 区域名称
- 前提条件:
    1. 首页登录
    2. 
- 测试步骤:
    1. 展开「商场管理」
    2. 点击「行政区域」
    3. 点击「北京市」左边的">"展开表单
    4. 点击「市辖区」左边的">"展开表单 
    5. 断言 区域名称包含 东城区, 
         然后断言当区域名称=北京市时, 区域类型=省，区域编码=110000
         断言当区域名称=市辖区时, 区域类型=市，区域编码=110100
         断言当区域名称=东城区时, 区域类型=区，区域编码=110101 
    6. 执行完成，退出浏览器
